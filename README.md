# LAMBODHARA 2.0 — The Signal Archive

A responsive, no-framework static site concept for a mystery-led campaign. All graphics are made with HTML/CSS; there are no paid dependencies, image assets, analytics, or server-side quiz collection.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **GitHub Actions** as the source.
3. The included workflow deploys the root folder when a commit reaches `main`. Check **Actions** for the deployment status.
4. Once successful, the expected URL is `https://shravansrijju.github.io/lambodhara2-archive/`.

## Before any official launch
This is an unofficial speculative campaign demo, not the official movie website. Keep the disclaimer unless the production team approves the campaign and grants the relevant rights. Verify all movie information directly with the makers. Replace placeholder artwork only with approved assets. Do not post fake police reports, missing-person claims, fabricated quotes, supposed leaks, or fictional events presented as real. The quiz runs locally and does not send answers to a server.
